# Job-specific CV workspace

This directory is the private working area for adapting the baseline CV to each vacancy. The leading dot makes it a hidden directory in normal file listings. It is repository working material and is not served as part of the website.

## Baselines
- `BASELINE_EN.md`: approved English ATS baseline.
- `BASELINE_FR.md`: approved French ATS baseline.
- `JOB_APPLICATION_TEMPLATE.md`: repeatable workflow and checklist for each vacancy.

## Every time a job post is provided
1. Create a dated folder, for example `2026-10-20-company-ai-intern/`.
2. Save the complete job post in `JOB_POST.md` (or save its URL and the relevant text if copyrighted content should not be copied in full).
3. Fill `FIT_ANALYSIS.md` using the template: mandatory requirements, preferred requirements, evidence from the baseline, genuine gaps, and keywords to use naturally.
4. Create `CV_EN.md` and/or `CV_FR.md` from the matching baseline, depending on the language of the application.
5. If useful, add `OUTREACH.md` for the recruiter message or cover letter.
6. Review the tailored CV against the job post and verify that every claim is supported by the user's actual education, projects, repositories, and experience.

## Non-negotiable rules
- Do not invent employment, internships, qualifications, certifications, metrics, tools, language levels, or project outcomes.
- Do not present collaborative work as an individual project; preserve the user's actual contribution.
- Do not claim access to private repositories or present private repository links as public.
- Tailor wording and ordering, not the underlying facts.
- Keep the CV one-column, text-first, ATS-readable, with consistent section spacing and standard headings.
- Keep both language versions equivalent in structure and truthful content, using natural English/French rather than literal translation.
- Do not overwrite either baseline when preparing a vacancy-specific version.
- Keep personal/job-specific copies in this directory only; do not add them to public website routes or public download assets unless the user explicitly asks.
